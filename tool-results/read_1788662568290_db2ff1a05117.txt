   370→  - toJpeg → toCanvas → toSvg → getImageSize(node, options)
   371→  - getImageSize uses options.width/height OR node.clientWidth/clientHeight (via getNodeWidth/getNodeHeight)

   381→  3. Lock dimensions on clone via inline style.width, style.height, style.minHeight, style.maxHeight
